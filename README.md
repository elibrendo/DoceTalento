# Doce Talento

Página da confeitaria artesanal com links para Instagram e WhatsApp e cardápio com pedidos pelo WhatsApp.

## Arquivos

- `index.html`: apresentação da marca e links.
- `css/style.css`: identidade visual em tons de chocolate e creme.
- `js/produtos.js`: telefone, mensagens, categorias e produtos.
- `js/app.js`: filtros do cardápio e links de pedido.
- `img/logo.png`: logo da Doce Talento.

## Atualizar o cardápio

Edite `js/produtos.js` para ajustar produtos, preços, descrições e categorias. O campo `detalhe` pode ser usado para indicar o peso ou a unidade; `icone` define o símbolo decorativo, sem usar fotos.

O número do WhatsApp deve ser informado em `LOJA.whatsapp` com código do país e DDD, somente números. Os links do Instagram ficam no `index.html`.

## Visualizar

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Publicar

O site é estático e pode ser publicado em hospedagens como GitHub Pages, Netlify ou Vercel.
